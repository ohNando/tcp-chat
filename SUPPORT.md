# Getting help

- **Questions, ideas, "how do I …":** ask in
  [Discussions](https://github.com/ohNando/tcp-chat/discussions).
- **Something is broken:** open a
  [bug report](https://github.com/ohNando/tcp-chat/issues/new/choose) with the
  steps to reproduce it and which client you used (terminal, web or desktop).
- **A security problem:** do not open a public issue; follow
  [SECURITY.md](SECURITY.md).
- **Want to help build something?** See [docs/ROADMAP.md](docs/ROADMAP.md)
  and [CONTRIBUTING.md](CONTRIBUTING.md).

This is a hobby and learning project, so answers may take a few days.
